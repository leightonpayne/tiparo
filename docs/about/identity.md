# Identity

## Name

"Tiparo" (/tiˈpaɾo/) means "Font" in
[Esperanto](https://en.wikipedia.org/wiki/Esperanto).

## Colours

The site uses [Flexoki](https://stephango.com/flexoki) neutrals by Steph Ango for
interface backgrounds, text, and borders. Tiparo's yellow (`#f2fdad`) marks
selected controls, focus states, and text highlights. The documentation uses
the same neutrals in its light and dark themes.

## Interface

The interface is minimal and brutalist: square corners, flat surfaces, bold
2px rules and outlined controls. A shared `--ui-rule-width` token keeps header,
list, specimen, metadata, canvas and control dividers consistent. The library opens
with a large, centered Tiparo logo and search field above its editable type list.
Font pages retain a compact sticky header with the logo at the top left.

Geist provides a consistent interface hierarchy, with bold page titles and
compact family names, credits and metadata. The specimens and mockups use
each selected typeface. The logo rises gently into place and grows to full size,
followed by the search field and a content fade. On font pages, the title,
specimens and metadata rise into view in sequence as you scroll; the mockup
viewer fades in without moving its images. Buttons respond with a small lift
and press, while the back logo and link icons provide brief hover feedback.
Filtering and specimen editing stay immediate, and reduced-motion preferences
disable these effects. Spacing and typography provide the structure without
decorative shadows.
The docs follow the same square, flat treatment while retaining light and dark themes.

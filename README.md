## Overview

"Tiparo" (/tiˈpaɾo/) is a personal library of typefaces I like using. Tiparo
means "Font" in [Esperanto](https://en.wikipedia.org/wiki/Esperanto).

The app is deployed to
[tiparo.leightonpayne.dev](https://tiparo.leightonpayne.dev).

Detailed docs are deployed to
[tiparo.leightonpayne.dev/docs](https://tiparo.leightonpayne.dev/docs).
